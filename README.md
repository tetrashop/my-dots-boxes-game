# 🧩 بازی مربع‌سازی (Dots and Boxes)

بازی کامل با هوش مصنوعی، سیستم امتیازدهی، و بلاکچین اختیاری - آماده Vercel.

## ✨ ویژگی‌ها

- 📐 شبکه قابل تنظیم (۳×۳ تا ۸×۸)
- 👥 ۲ تا ۴ بازیکن
- 🎨 رنگ دلخواه برای هر بازیکن
- 🤖 هوش مصنوعی با اولویت مربع‌سازی
- 🏆 سیستم امتیاز، پاداش، جریمه
- 🔐 ثبت‌نام با نام، ایمیل، تلفن
- 💰 جایزه روزانه
- ⛓️ اتصال اختیاری به Sepolia
- 📱 کاملاً واکنش‌گرا

## 🚀 نصب و اجرا

```bash
npm install
npm run dev
```

📦 دیپلوی روی Vercel

```bash
git add .
git commit -m "deploy"
git push origin main
vercel --prod
```

🔧 متغیرهای محیطی در Vercel

کلید مقدار
NEXT_PUBLIC_NETWORK sepolia
NEXT_PUBLIC_RPC_URL https://ethereum-sepolia-rpc.publicnode.com
NEXT_PUBLIC_CONTRACT_ADDRESS 0xe2899bddFD890e320e643044c6b95B9B0b84157A
