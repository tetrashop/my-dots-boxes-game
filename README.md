# 🧩 بازی مربع‌سازی (Dots and Boxes)

یک بازی کامل مربع‌سازی با هوش مصنوعی، انتخاب رنگ، و تست خودکار، ساخته شده با Next.js و قابل دیپلوی روی Vercel.

## ✨ ویژگی‌ها

- 🎨 انتخاب رنگ دلخواه برای هر بازیکن
- 🔴 خطوط رنگی برای هر بازیکن
- 📢 نمایش نوبت فعلی
- 🛡️ جلوگیری از حرکت در نوبت اشتباه
- 🤖 هوش مصنوعی با اولویت مربع‌سازی
- 🧪 تست خودکار برای بررسی عملکرد
- 📱 طراحی واکنش‌گرا (Responsive)

## 🚀 نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرا در حالت توسعه
npm run dev

# ساخت نسخه تولید
npm run build
npm start
```

📦 دیپلوی روی Vercel

```bash
# نصب Vercel CLI
npm i -g vercel

# دیپلوی
vercel
```

🧪 تست خودکار

با کلیک روی دکمه "تست خودکار" می‌توانید عملکرد بازی را بررسی کنید:

· حرکت معتبر
· جلوگیری از حرکت تکراری
· تشخیص نوبت
· ساخت مربع

🎮 نحوه بازی

1. روی خطوط بین نقاط کلیک کنید تا خط بکشید
2. هر بار که یک مربع کامل شود، امتیاز می‌گیرید
3. هوش مصنوعی به صورت خودکار حرکت می‌کند
4. برنده کسی است که بیشترین مربع را ساخته باشد

📁 ساختار پروژه

```
/my-dots-boxes-game/
├── /components/     # کامپوننت‌های React
├── /pages/         # صفحات و API
├── /styles/        # استایل‌ها
├── /utils/         # منطق بازی
└── package.json    # وابستگی‌ها
```
